# ترجِم (Tarjem)

**مترجم للشاشة من الإنجليزية إلى العربية، يعمل من شريط القوائم في macOS.**
اضغط الأيقونة، ثم حدّد جزءاً من الشاشة أو اختر الشاشة كاملة، فتظهر العربية **فوق النص الأصلي في مكانه**، كما في Google Lens أو الترجمة في تطبيقات Apple.

- 🔒 **على جهازك**: قراءة النص بمحرك Live Text، والترجمة بمحرك Apple دون إنترنت. Google احتياط اختياري.
- 🎯 **في المكان نفسه**: العربية بألوان الواجهة الأصلية، ومفتاح المسافة يعيد عرض الأصل.
- 📝 **فقرات لا أسطر**: تُجمع الأسطر في جمل كاملة قبل الترجمة، فتخرج العربية أسلس.
- ⌨️ **اختصارات عامة** تعمل من أي تطبيق.

فكرة المشروع كاملة بعد تطويرها، مع خارطة الطريق، في [`docs/IDEA.md`](docs/IDEA.md).

## الاستخدام

| الإجراء | الاختصار |
|---------|----------|
| ترجمة جزء من الشاشة (اسحب مستطيلاً) | `⌥⇧T` |
| ترجمة الشاشة كاملة | `⌥⇧F` (أو المسافة أثناء التحديد) |
| ترجمة النص المحدّد أو المنسوخ | `⌥⇧V` |

**أثناء عرض الترجمة:**

| المفتاح | ما يفعله |
|---------|----------|
| `مسافة` | التبديل بين الأصل والترجمة |
| `⌘C` | نسخ الترجمة |
| `Esc` | إغلاق الترجمة |

مرور الفأرة على أي مقطع يعرض نصه الإنجليزي. زر 📌 يثبّت الترجمة على الشاشة، وزر النص يفتحها في نافذة فيها نسخ واستماع.

يمكنك تغيير مفاتيح التعديل (`⌥⇧` أو `⌃⌥` أو `⌃⇧`) ومحرك الترجمة وطريقة العرض من **الإعدادات**.

## التثبيت

يتطلب **macOS 15 (Sequoia) أو أحدث**.

### الطريقة الأولى: تنزيل نسخة جاهزة

1. افتح تبويب **Actions** في المستودع، ثم آخر تشغيل ناجح لـ **Build**.
2. نزّل الملف **Tarjem-macOS**، وفك ضغطه، وانقل `Tarjem.app` إلى مجلد **التطبيقات**.
3. النسخة غير موثّقة من Apple، فسيرفض النظام فتحها في المرة الأولى. افتح **إعدادات النظام ← الخصوصية والأمان** واضغط **«فتح على أي حال»**، أو نفّذ في الطرفية:

</div>

```bash
xattr -dr com.apple.quarantine /Applications/Tarjem.app
```

<div dir="rtl">

### الطريقة الثانية: البناء من المصدر

تحتاج Xcode 16 أو أدوات سطر الأوامر (`xcode-select --install`):

</div>

```bash
git clone https://github.com/muhmaadd/muhmaadd.git && cd muhmaadd
./scripts/build-app.sh --install     # يبني ويثبّت في /Applications ثم يشغّل التطبيق
```

## الأذونات

| الإذن | لماذا | هل هو ضروري؟ |
|-------|-------|---------------|
| **تسجيل الشاشة** | لقراءة النص من الشاشة | نعم |
| **تسهيلات الاستخدام** | لترجمة النص المحدّد مباشرة دون نسخه يدوياً | لا، فبدونه تُترجم محتويات الحافظة |

يطلب macOS إذن تسجيل الشاشة عند أول استخدام. **بعد منحه أعد تشغيل التطبيق** (يوجد زر لذلك في رسالة التنبيه).

> **ملاحظة للمطوّرين:** كل بناء جديد موقّع توقيعاً محلياً (ad-hoc) يعدّه النظام تطبيقاً جديداً، فقد يطلب الإذن مرة أخرى. احذف «ترجِم» من القائمة في إعدادات الخصوصية ثم أضفه من جديد.

## الترجمة دون إنترنت

عند اختيار محرك Apple تحتاج حزمة العربية منزّلة على الجهاز. نزّلها بإحدى طريقتين:

- **من التطبيق:** الإعدادات ← الترجمة ← زر **«تنزيل»**.
- **من النظام:** إعدادات النظام ← عام ← اللغة والمنطقة ← لغات الترجمة.

إلى أن تنزّلها، يستخدم ترجِم Google تلقائياً (يمكن إيقاف ذلك من الإعدادات).

## حل المشكلات

- **لا تظهر الأيقونة في شريط القوائم:** قد يكون الشريط ممتلئاً، خاصةً على الشاشات الصغيرة ذات النتوء. استخدم الاختصارات، أو أخفِ أيقونات أخرى.
- **الاختصار لا يعمل:** قد يستخدمه تطبيق آخر. غيّر مفاتيح التعديل من الإعدادات.
- **رسالة «رفض Google الطلب»:** وصلت إلى حد مؤقت للطلبات. انتظر قليلاً، أو نزّل حزمة العربية لتعمل الترجمة على الجهاز.

## بنية المشروع

</div>

```
Sources/
  TarjemCore/          منطق مستقل عن النظام + اختبارات (يعمل على Linux أيضاً)
    TextBlockGrouper   تجميع أسطر OCR في فقرات وترتيب القراءة
    ColorSampler       استخراج لون الخلفية ولون الخط من اللقطة
    TextTools          دمج الأسطر، الكلمات المقسومة، تقسيم النص الطويل
    GoogleTranslateAPI بناء الطلب وتحليل الاستجابة
  Tarjem/              تطبيق macOS
    AppDelegate        أيقونة شريط القوائم، القائمة، الاختصارات، تسلسل العمل
    SelectionOverlay   تعتيم الشاشة وتحديد المنطقة
    ScreenCapture      التقاط الشاشة (ScreenCaptureKit)
    TextRecognizer     قراءة النص (Vision)
    TranslationJob     حالة الترجمة: OCR ← فقرات ← Apple / Google
    OverlayView        رسم العربية فوق الأصل + شريط الأدوات
    TextPanel          نافذة النص: نسخ واستماع
    SettingsView       الإعدادات والأذونات وتنزيل حزمة العربية
scripts/build-app.sh   بناء Tarjem.app وتوقيعه وضغطه
```

```bash
swift test                     # اختبارات TarjemCore
UNIVERSAL=1 ./scripts/build-app.sh   # نسخة تعمل على Apple Silicon وIntel
```

---

**English:** Tarjem is a macOS menu-bar app that translates on-screen English text into Arabic in place (Lens-style). Pick a region or the full screen: it captures with ScreenCaptureKit, runs OCR with Vision, groups lines into paragraphs, translates on-device with Apple's Translation framework (Google web endpoint as fallback), then paints the Arabic over the original using colors sampled from the screenshot. Requires macOS 15+. Build with `./scripts/build-app.sh`.
