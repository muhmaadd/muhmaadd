# العلامات

كل علامة لها مجلد باسمها (أحرف لاتينية صغيرة وشرطات)، تنشئه وتحدّثه مهارة `adobe-brand-designer`:

```
brands/
  <slug>/
    brand-profile.md   القواعد الثابتة، الهوية، النمط المستخرج، التصاميم المعتمدة
    assets/            الشعار بنسخه والتصاميم المرجعية
```

تقرأ المهارة `brand-profile.md` في بداية كل جلسة، فلا تُعاد أسئلة الهوية والنمط.
